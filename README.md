# Portafolio DataGob · QROMA

Demo agéntica para la gestión de la demanda de proyectos de datos en QROMA.

## Propósito

Construir una plataforma separada de DataOps para gestionar el ciclo completo de la demanda de datos: captura, clasificación, evaluación, priorización, decisión de comités, seguimiento y pase de MVP a producción.

## Principios

- Spec-Driven Development como fuente de verdad.
- Gobierno de datos por dominios y subdominios.
- Agentes especializados para apoyar la gestión de demanda.
- Infraestructura como código sobre Google Cloud.
- Separación clara frente a la demo DataOps.

## Estado

Repositorio inicializado para construir la demo bajo el enfoque Atlas Designpro + Spec Driven Delivery.
