## Objetivo

Preparar ATLAS DataGob para cierre de release candidate `v1.0-rc1`, dejando documentados los gates, evidencias, criterio de salida y tag recomendado.

## Cambios incluidos

- Documento `docs/release/release-candidate-v1.0.md`.
- Documento `docs/release/version-tag-and-exit-checklist.md`.
- Checklist de gates técnicos y funcionales.
- Tag recomendado `atlas-datagob-v1.0-rc1`.
- Criterios GO / NO-GO.
- Secuencia sugerida para crear el tag después del merge.

## Enfoque

Este sprint no introduce funcionalidad nueva. Es un incremento de control de release, orientado a estabilizar el producto, ordenar la salida y preparar el handoff final.

## Validación esperada

- API tests.
- Web build.
- Container build API/Web.
- Deploy scripts validation.

## Impacto esperado

ATLAS DataGob queda listo para declarar un release candidate controlado, con evidencia suficiente para pasar al último sprint de handoff ejecutivo-operativo.
