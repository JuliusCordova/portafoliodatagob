# Sprint 33 · Product landing documentation and demo run consolidation

## Objetivo

Consolidar la documentación de ATLAS DataGob en una entrada clara de producto, facilitando la navegación para sponsors, equipo técnico, operadores de demo, operación y comité de release.

---

## Alcance implementado

- README principal convertido en landing del producto.
- Guía `Start here` por rol.
- Mapa de navegación del repositorio.
- Guía consolidada de ejecución de demo.
- Índice documental integral.

---

---

## Resultado esperado

Cualquier persona que ingrese al repositorio debe poder responder rápidamente:

1. Qué es ATLAS DataGob.
2. Qué problema resuelve.
3. Qué capacidades tiene.
4. Cómo correrlo localmente.
5. Cómo preparar una demo.
6. Cómo ejecutar piloto Cloud Run.
7. Cómo revisar evidencia.
8. Cómo promover un release candidate.
9. Cómo planificar producción gestionada.

---

## Validación esperada

- API tests.
- Web build.
- Container build API/Web.
- Deploy scripts validation.

---

## Decisión de diseño

Este sprint no agrega nueva lógica de negocio. Su valor está en consolidar el producto como paquete consumible y defendible, reduciendo fricción para revisión ejecutiva, técnica y operativa.
